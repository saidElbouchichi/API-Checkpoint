# API Checkpoint — GOMYCODE

Application React qui consomme l'API **JSONPlaceholder** pour afficher une liste d'utilisateurs.

- `src/UserList.js` : `axios.get` dans `useEffect`, données stockées avec `useState` dans `listOfUser`, puis `map()` pour afficher chaque utilisateur.
- Gestion du chargement et des erreurs.

```bash
npm install
npm start
```
